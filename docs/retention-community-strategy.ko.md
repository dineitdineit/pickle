# Pickle 재방문과 교류 전략 제안

작성일: 2026-10-15
상태: SNS 공식 자료와 창업자 목적에 근거한 자문안. 구현된 기능 목록이나 확정 출시 일정은 아니다.
기준: [제품 방향서](./product-vision.ko.md)

## 1. 전략의 중심

> **혼자 와도 다음 한 끼를 고를 수 있고, 참여하면 누군가와 대화가 이어지는 음식 커뮤니티를 만든다.**

초기 집중 주제로 ‘필리핀에서 실제로 만들어 먹기 좋은 일상 요리’를 추천한다. 정확한 음식·언어·이용자 범위는 모집 대상과의 대화로 좁힌다. 일반 음식 사진과 실패 경험은 계속 공유할 수 있게 두고, 초기 콘텐츠 편집과 모집의 초점을 맞춘다는 뜻이다.

유료 게시물·구독제는 창업자가 정한 이용 규모 조건 전까지 도입하지 않는다. 이 전략은 게시 보상이나 유료 참여를 필수 조건으로 두지 않는다. 크리에이터 활동비 지원 여부는 별도 결정이다.

## 2. 다른 SNS에서 가져올 구조

아래 자료는 각 서비스가 제공하는 기능·운영 방식을 확인하는 근거다. 해당 기능이 그 서비스의 성장을 단독으로 일으켰다는 인과 증거나, pickle의 재방문율을 보장하는 공식은 아니다.

## 3. 세 가지 돌아올 이유

### 나를 위해 쌓아 둔 음식

음식 사진을 구경한 뒤 ‘이번 주 해보고 싶다’는 메뉴를 저장한다. 저장한 것을 찾기 쉽고, 재료와 조리법을 읽기 쉬워야 한다. 첫 방문에서 다른 이용자와 대화하지 않아도 얻는 가치를 만든다.

새 이용자에게 프로필 완성이나 게시를 먼저 요구하기보다 음식 탐색과 저장을 먼저 경험하게 하는 방식을 제안한다. 계정이 필요한 행동에서 가입 이유를 설명하고, 팔로우와 참여는 다음 선택으로 둔다.

### 나에게 돌아온 실제 반응

사용자는 레시피에 질문하거나 사진과 짧은 글을 올린다. 만든 사진은 원본 레시피에 연결할 수 있고, 작성자는 이를 알아보고 답할 수 있다. 답글은 해당 대화로 연결되며, 이용자가 원하면 계속 대화를 따라갈 수 있다.

예: A가 올린 레시피를 B가 저장 → B가 대체 재료를 질문 → A의 답을 확인하러 B가 재방문 → B가 만든 사진을 공유 → A가 후기를 보고 답글 → C가 실제 결과를 보고 저장한다.

댓글이나 후기는 선택이다. 구경·저장만 하는 사람도 이용 가치가 있고, 모든 이용자가 요리하거나 게시해야 하는 구조로 만들지 않는다.

### 함께하는 다음 음식 경험

초기에는 운영자가 하나의 주간 주제를 연다. ‘이번 주 계란 요리’, ‘남은 재료로 한 끼’처럼 참여자가 같은 재료·문제를 두고 이야기할 수 있는 주제다. 지역 가격을 검증하기 전에는 임의의 예산 한도를 필수 조건으로 내걸지 않는다.

한 주의 예시 리듬은 주 초 레시피와 질문, 주 중 요리·실패 사진과 도움, 주말 서로 다른 결과와 경험 소개다. 참여 시점과 횟수는 자유롭게 두고 기존 콘텐츠도 탐색할 수 있게 한다.

좋아요 순위만으로 대표 게시물을 고르지 않는다. 유용한 답변, 재료 대체, 첫 참여, 실패에서 배운 점도 소개한다. 이를 통해 평범한 이용자가 다음 주에도 참여할 이유를 찾도록 한다. 콘텐츠 재소개는 공개 범위와 작성자의 의사를 존중한다.

## 4. 초기 밀도를 만드는 운영

1. 함께 참여할 수 있는 음식 주제를 다루는 작은 크리에이터부터 개별 초대한다. 초대장에는 실제 레시피 화면, 다른 SNS 계정 연결, 초기 기획에 의견을 낼 기회 등 제공 가능한 가치를 제시한다. 트래픽·수익은 보장하지 않는다.
2. 요리법을 찾거나 따라 만들고 싶은 독자도 별도로 모집한다. 크리에이터의 외부 SNS에서 원본 레시피 링크를 공유하는 활동은 동의를 받아 협의한다.
3. 처음에는 여러 빈 그룹으로 나누기보다 하나의 홈과 하나의 주간 주제에 참여를 모은다. 관심사별 대화가 실제로 반복되면 별도 공간을 검토한다.
4. 창업자는 게시물 공급과 함께 질문·첫 게시물을 살핀다. 초기에 답이 없는 질문을 하루 안에 확인하는 것을 운영 목표로 삼되, 모르는 내용에 답을 지어내거나 이용자의 응답을 강제하지 않는다. 실제 응답 소요 시간을 측정한다.
5. 반응은 실제 경험과 관심에 근거한다. AI가 일반 이용자인 것처럼 댓글을 달거나, 허위 계정·좋아요 교환으로 활동을 만들지 않는다.

## 5. 제품 우선순위

| 우선순위 | 필요한 경험 | 처음 검증할 이유 |
| --- | --- | --- |
| 우선 1 | 보기 편한 레시피, 목적 있는 저장과 재열람 | 교류가 적어도 다시 쓸 이유 |
| 우선 2 | 사진+짧은 글, 원본 레시피와 후기 연결, 질문·답글 | 일반 이용자의 가벼운 참여와 실제 관계 |
| 우선 3 | 원본 작성자·답글 대상에게 관련 활동 전달, 대화로 이동 | 진행 중인 관계를 이어갈 이유 |
| 우선 4 | 주간 주제와 참여 게시물 모음 | 같은 주제를 공유하는 반복 참여 |
| 이후 | 이용량에 따른 취향 추천·공간 분화·기여 소개 자동화 | 관찰된 문제를 규모에 맞게 해결 |

알림은 사용자가 선택한 채널·설정을 존중한다. 답변·후기처럼 관련성이 높은 활동을 우선하고, 같은 사건의 중복 알림을 묶는다. 주간 소식은 선택 가능한 요약으로 시작한다. 알림을 열었는지만이 아니라 대화가 이어졌는지와 알림 끄기·이탈도 함께 본다.

홈에서는 저장한 음식, 팔로우한 사람과 대화 중인 게시물, 새로운 음식과 이번 주 주제를 함께 찾을 수 있게 한다. 정확한 배치·비율은 실제 사용을 보고 정하며, 팔로우 콘텐츠가 적으면 빈 화면 대신 주제 콘텐츠를 제공한다.

저장·직접 만든 후기·도움이 되는 답변을 추천과 편집에 참고하되, 단순 개수로 정확성을 판정하지 않는다. 신규 작성자에게도 발견 기회를 주고 인기 게시물 독점을 살핀다. 초기에는 운영자 편집과 간단한 주제 선택으로 검증할 수 있다.

## 6. 측정할 것

페이지를 다시 연 것, 콘텐츠를 다시 사용한 것, 사람과 대화를 이어간 것을 구분한다. 처음 온 시기별로 집단을 묶고 크리에이터와 일반 이용자를 나누어 관찰한다.

| 지표 | 이 문서에서의 정의 |
| --- | --- |
| 다음 주 이용 유지율 | 첫 방문일 기준 7~13일에 한 번 이상 레시피 상세·저장목록을 보거나 저장·게시·댓글 등 의미 있는 행동을 한 사람 / 같은 첫 방문 집단 중 해당 기간 관찰을 완료한 사람 |
| 4주 후 이용 유지율 | 위와 같은 기준으로 첫 방문일 기준 28~34일에 활동한 비율. 정확히 28일째의 D28 지표와 구분 |
| 첫 반응 도달 | 첫 게시·질문 후 다른 사람의 실제 관련 답변을 받기까지의 시간과, 답변을 받은 비율. ‘24시간 내’도 별도 표시 |
| 이용자 간 대화 | 창업자·운영진을 제외한 서로 다른 두 이용자 사이에 댓글과 답글이 오간 관계 수·참여자 수 |
| 관계의 반복 | 이용자 간 대화 참여자 중 다음 주에도 다른 이용자와 대화한 사람의 수와 비율 |
| 저장의 재사용 | 저장한 뒤 다른 날짜에 원본이나 저장목록을 다시 사용한 사람의 수와 비율 |
| 경험 연결 | 원본 레시피에 연결된 실제 후기와 이를 올린 사람의 수 |

주간 핵심 관찰값은 ‘서로 대화를 주고받은 일반 이용자 수’이며, 단순 탐색 이용자의 유지율도 함께 본다. 이모지·자동 반응·스팸을 대화로 과대 계산하지 않는다. 창업자와 지원받은 활동은 구분해 보여주되 실제 크리에이터의 정상 참여를 무가치하게 취급하지 않는다.

특정 행동을 한 사람이 더 많이 돌아온다고 해서 그 기능이 재방문을 일으켰다고 단정하지 않는다. 원래 관심이 큰 사람일 수 있다. 가능하면 비슷한 모집 집단에서 변경 전후를 비교하고, 규모가 충분하면 실험을 설계한다. 작은 표본에서는 인원과 실제 경험을 함께 기록한다.

## 7. 8주 검증 제안

예시 모집 규모는 크리에이터 5~10명, 콘텐츠를 사용할 독자 30~50명이다. 적정 규모나 성공 기준으로 검증된 숫자는 아니며 응답률과 운영 여력에 맞춘다.

- **1~2주:** 첫 방문에서 음식 발견·저장·재열람이 되는지, 첫 질문과 게시물에 실제 답이 오는지 확인한다. 주제는 하나로 시작한다.
- **3~4주:** 원본과 연결된 만든 사진, 주간 주제와 대화를 운영한다. 처음 온 집단의 다음 주 이용과 관계의 반복을 확인한다.
- **5~6주:** 운영자의 개인 독려와 일반 이용자 활동을 구분하고, 직접 독려하지 않아도 유지되는 관계를 관찰한다. 기본적인 응답·안전 관리는 유지한다.
- **7~8주:** 관찰 가능한 초기 집단의 4주 후 유지율과 면담을 종합한다. 다음 집단의 재현 여부를 검토한다.

숫자 목표는 첫 관찰값을 보고 다음 모집 전에 정한다. 기존 데이터 없이 임의의 재방문율을 업계 기준처럼 제시하지 않는다.

## 8. 결과에 따라 내릴 결정

| 관찰 결과 | 다음 행동 |
| --- | --- |
| 저장한 음식을 다시 찾고, 이용자끼리 대화도 반복된다 | 같은 음식 관심사를 가진 소규모 집단을 추가 모집 |
| 저장·재열람은 반복되지만 교류가 적다 | 질문 주제와 후기 연결을 개선하며 정보·도구 가치도 유지 |
| 댓글은 많지만 늘 같은 소수만 돌아온다 | 신규 이용자에게도 가치와 반응이 전달되는지 점검 |
| 창업자가 연락해야만 활동한다 | 초대 대상을 늘리기 전에 음식 주제·참여 부담·돌아올 이유를 수정 |
| 알림 열람은 늘지만 대화와 이용이 남지 않는다 | 알림 양 확대 대신 실제 답변과 콘텐츠 가치 개선 |

유료화는 회원 총수 하나만으로 시작 시점을 정하지 않는다. 창업자가 정한 이용 규모 조건을 충족한 뒤 반복 이용·운영 비용·지불 의사와 함께 별도로 판단한다. 초기 전략의 초점은 음식의 개인적인 쓸모, 실제 사람의 반응, 반복되는 공동 경험이다.
