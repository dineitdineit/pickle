# 만 13세 계정의 보호자 동의

기준일 2026-10-16 · 규칙 `13-plus-guardian-v1` · 약관/콘텐츠 정책 `2026-10-16.1`

만 13세 미만은 계정 활성화를 허용하지 않습니다. 만 13세는 보호자 확인 후 활성화하고 만 14세 이상은 일반 연령 확인을 거칩니다. 기존 18+ 확인 기록은 유지합니다. 새 앱은 `get_account_age_status_v2`와 `confirm_account_age_v2`를 사용하며 기존 앱의 18+ RPC 응답은 호환성을 위해 유지합니다. 생년월일은 판정에만 사용하고 저장하지 않습니다. 연령 입력은 자기신고이며 실연령 인증은 아닙니다.

## 보호자와 운영자가 진행할 절차

1. 로그인 후 만 13세로 확인되면 요청 번호와 동의 대기 화면이 나옵니다. 해당 화면의 개인정보처리방침·이용약관·콘텐츠 정책을 보호자에게 보여줍니다. 요청에 연결된 서버 정책 버전이 일치해야 이메일 문구를 준비할 수 있습니다.
2. 성년인 부모/법정대리인이 본인의 이메일에서 `admin@getpickleapp.com`으로 요청 번호·정책 버전·이름·관계와 명시적인 YES 동의를 보냅니다. 이메일 준비 버튼은 메일 작성기를 열 뿐이며, 전송하거나 계정을 자동 승인하지 않습니다. 신분증이나 자녀의 전체 생년월일을 보내도록 요구하지 않습니다.
3. 운영자는 공식 메일함에서 수신·명시적 동의·해당 계정과의 연결·법정대리 권한을 확인합니다. 자녀가 대신 보낸 자기확인 문구만으로 승인하지 않습니다. 불명확하면 필요한 범위에서 추가 확인하고, 권한을 확인할 수 없으면 승인하지 않습니다. 시스템은 자동 신원인증 서비스를 제공하지 않습니다.
4. Admin dashboard > Moderation > Guardian consent requests에서 (상태 선택 및 Previous/Next 페이지 이동 가능) 요청 번호와 버전을 대조합니다. 실제 확인을 완료한 경우에만 확인 체크박스와 내부 사건/증빙 참조 번호를 넣고 Approve activation을 누릅니다. 원문 이메일·이름·신분증을 참조 번호 칸에 복사하지 않습니다. 권한은 DB 관리자 역할로 검사하며 본인의 요청은 승인할 수 없습니다.
5. 승인 후 사용자가 Retry eligibility check를 누르거나 주기적 확인이 성공하면 활성화됩니다. 게시 전 콘텐츠 약관 동의는 별도로 필요합니다.
6. 보호자 철회 요청을 확인하면 approved 목록에서 참조 번호를 적고 Record withdrawal and pause account를 누릅니다. 서버 일반 쓰기가 제한되고 프로필·공개 콘텐츠를 숨깁니다. 계정 삭제 요청이면 기존 삭제 절차를 진행합니다. 정당한 재검토가 끝난 경우에만 새로운 증빙으로 다시 승인할 수 있으며 처리 이력은 남습니다.

## 데이터와 보관

- 비공개 DB에는 계정/요청 ID, 정책 버전, 상태, 시각, 담당자 ID와 내부 증빙 참조 번호 및 결정 이력만 보관합니다. 일반 클라이언트의 직접 변경은 금지합니다.
- 승인된 요청·처리 이력은 활성 계정의 동의 근거로 보관하고 계정 삭제와 함께 삭제합니다. 대기·반려·철회 요청과 그 처리 이력은 요청/마지막 검토 후 30일에 정리합니다. 기록이 만료되어도 보호자 필요 여부가 해제되거나 자동 활성화되지는 않습니다.
- 동의는 정책 버전에 연결됩니다. 새 정책에서 다시 확인이 필요해지면 이전 승인을 새 버전에 자동 복사하지 않습니다. 과거 13세 선언을 다른 생년월일 입력으로 우회하거나 자동 성인 전환하지 않습니다. 연령 정정은 운영자에게 문의합니다.
- 실제 동의 이메일은 Porkbun 전달 및 Gmail 공식 문의 경로에 남습니다. DB 파기 작업은 외부 메일함·공급자 백업을 지우지 않습니다. 운영자가 계정 삭제/동의 철회 처리 시 관련 메일도 확인하고 목적이 끝난 사본을 별도로 정리해야 합니다. 메일함 보관 설정까지 자동화되었다고 안내하지 않습니다.
- 이미 발급된 이미지 URL(짧은 유효시간), 캐시 및 타인이 받은 사본은 즉시 모두 회수되지 않습니다. 승인은 새로운 노출을 허용할 뿐 삭제된 콘텐츠를 복원하지 않습니다.

## 출시 전 운영 확인

보호자 메일 수신 → 실제 권한 확인 → 승인 → 게시 → 철회 → 일반 기능 제한 → 삭제까지 실기기로 확인해야 합니다. 승인 클릭만으로 법정대리인 확인의 실효성이나 모든 국가의 법적 준비가 완료되는 것은 아닙니다. 필리핀을 먼저 대상으로 유지하고 국가 추가마다 연령/동의·국외 처리 의무를 검토합니다. Play Console 대상 연령은 13–15, 16–17, 18+ 실제 대상과 일치시켜 검토하며 콘텐츠 등급과 별개입니다. 어린이/청소년 대상 사회적 기능의 안전 안내·성인 관리 요구와 아동 안전 담당자 절차도 출시 전에 확인합니다. 이번 작업은 스토어 설정이나 배포를 하지 않습니다.

## 검증 결과

로컬 자동 테스트, 타입 검사, 웹 빌드/Capacitor 동기화와 Android debug APK 빌드를 실행했습니다. `tests/guardian-consent.integration.sql`, `tests/guardian-retention.integration.sql`, `tests/account-age-deletion.integration.sql`을 운영 DB의 합성 계정으로 BEGIN/ROLLBACK 실행하여 경계 연령, 권한 우회 차단, 승인·철회, 비공개 프로필, 30일 정리, 정책 변경 재확인, 기존 앱 호환과 계정 삭제 CASCADE를 확인했습니다. 실제 보호자 이메일 송수신·권한 확인은 운영자가 진행할 별도 수동 확인입니다. 실제 사용자 계정은 테스트로 삭제하지 않았습니다.
