이는 현재 소스/서버에서 확인한 입력 자료이며 Play Console에 제출한 확정 답변이 아닙니다.

이름/이메일/사용자 ID: 계정 관리·앱 기능·보안. Supabase Auth/DB 및 인증/안내 이메일 제공자.
사진: 선택적 프로필/레시피/대화 업로드, Supabase Storage. 정상 새 업로드에서 원본 메타데이터 제거. 기존 파일/직접 API/예전 APK는 별도 검토.
기타 사용자 콘텐츠: 레시피/댓글/리뷰/소개/신고/문의, 앱 기능·안전 처리.
메시지: 개인 대화 텍스트/사진, 앱 기능. 종단간 암호화로 분류하면 안 됨.
앱 활동: 검색 기록/팔로우/좋아요/저장/조회/알림 선택, 앱 기능·추천·집계·안전. 공개 API는 집계 조회만 제공하지만 서버의 원시 처리 사실을 누락하지 않음.
기술 정보/진단: 공급자 로그의 실제 필드·IP/사용자 에이전트·식별자 처리/위치 추론 여부와 외부 분석 설정을 확인한 후 해당 항목을 확정.
광고 ID·연락처·정밀 위치 권한·마이크: 검사한 앱/병합 debug manifest에서 사용 근거 없음. 서비스 제공자나 기존 이미지 메타데이터까지 일괄 '아무 위치 정보도 없음'으로 단정하지 않음.
외부 SDK: Supabase JS, Capacitor App/Browser. 전용 광고·외부 분석·원격 오류 수집 SDK 미통합. SDK와 앱이 관리하는 WebView의 외부 전송도 검토 대상.

'기기에서 외부로 보내는가'와 '공개 게시인가'는 다른 분류입니다. 비공개 대화·초안도 서버로 전송되면 수집 검토 대상입니다. 제공자 위탁 처리와 사용자가 지시한 공유의 예외는 실제 계약/동작을 공식 안내와 대조한 뒤 판단하세요. 모든 외부 서비스를 무조건 공유 '아니오'로 체크하지 마세요.
공식 작성 기준: https://support.google.com/googleplay/android-developer/answer/10787469

삭제 기능/전송 암호화의 실제 동작, 웹 외부 계정 삭제 요청 URL, 공개 개인정보처리방침 URL, 최종 출시 AAB와 실제 네트워크를 확인한 뒤 제출해야 합니다. 본 작업은 스토어 제출·승인 또는 법률 검토 완료를 의미하지 않습니다.
