ACCOUNT DELETION IMPLEMENTATION NOTE
The deployed deletion function first prepares an account-scoped deletion state, hides its recipes and prevents new ordinary writes. It uses the Storage API to remove paginated avatar/recipe/chat images, then requests Auth account deletion. Published recipes now cascade with account removal. Completion is returned only after Auth deletion; partial failures require explicit retry/support and can leave a restricted account with some files already removed. This is not a transaction that can undo deleted files. No live account was deleted during verification.
