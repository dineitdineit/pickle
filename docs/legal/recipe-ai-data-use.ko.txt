Pickle 레시피 AI 정리 — 활성화 전 확인 사항
작성일: 2026-10-16

현재 상태
- 운영자가 2026-10-16 Gemini 2.5 Flash Lite 선택 및 서버 Secrets 저장, RECIPE_AI_ENABLED=false를 보고했다. Vercel 플랜은 Hobby/Free다. 로컬 CLI 인증이 없어 실제 저장값은 독립 검증하지 못했으며 키를 읽거나 출력하지 않았다.
- RECIPE_AI_ENABLED=true, AI_GATEWAY_API_KEY, RECIPE_AI_MODEL이 모두 설정되기 전에는 외부 AI 호출이 발생하지 않는다.
- 실제 모델 응답 품질, 제공업체의 보관기간·처리국가·학습 설정은 아직 검증하지 않았다.

준비된 처리 흐름
- 이용자가 화면의 안내를 읽고 Organize with AI를 누를 때만 재료 및 조리 단계 텍스트 두 항목을 Supabase 서버를 거쳐 Vercel AI Gateway와 Google Vertex AI (Gemini 2.5 Flash Lite)에 전달한다.
- 목적은 자유 형식 텍스트를 수정 가능한 재료·조리 단계 필드로 정리하는 것이다. 자동 게시하지 않는다.
- 이 함수는 사진, 이메일, 프로필, 다른 레시피 정보, 메시지를 모델에 전달하지 않는다. 외부 업체의 통신·접속 로그 처리는 별도다.
- 입력 원문은 기존 비공개 레시피 초안 및 기기 초안에 보존한다. AI 응답 전용 아카이브는 만들지 않는다. 제안 적용 시 정리된 필드가 일반 레시피 초안/게시물로 저장된다.
- 비공개 사용량 기록은 계정 ID·UTC 일자·횟수·최근 요청 시간만 포함한다. 계정 삭제 시 연쇄 삭제하며, 일일 정리 작업에서 전날보다 오래된 기록을 삭제한다. 전체 일별 횟수에는 계정 ID가 없다.

실제 활성화 전에 확정·고지할 정보
1. 선택한 모델과 실제 처리 제공업체의 법인명, 제공 목적, 전달 항목, 처리국가 및 국외 이전 관련 요건.
2. Vercel Gateway와 해당 모델 제공업체의 입력/출력/로그 보관기간, 삭제·학습 이용 조건 및 실제 설정. 앱의 30일 삭제 정책이 외부 업체 사본에 자동 적용된다고 안내하지 않는다.
3. 현재 개인정보처리방침과 동의 문구에 해당 선택 기능을 반영하고, 변경 정도에 따라 재동의 및 만 13세 보호자 동의 범위·갱신 절차를 검토한다. 현재 일반 약관 동의 버전은 변경하지 않고, 별도 AI 체크박스 및 요청 버전 recipe-ai-2026-10-16.1을 요구한다. 기존 만 13세 보호자 승인을 이 새로운 AI 처리의 승인으로 간주하지 않는다. requires_guardian 계정은 별도 AI 보호자 승인 절차 구현 전까지 서버에서 AI 요청을 차단한다. 수동 레시피 입력은 유지한다.
4. 화면의 AI 별도 안내에도 실제 모델 제공업체를 표시한다. 일반 게시 약관 동의를 이 선택적 외부 전송의 동의로 대신하지 않는다.
5. 실제 합성 레시피로 추출 품질, 원문 외 재료 추가 여부, 소수/분수, 언어 유지, 실패와 제한 동작을 확인한다.

키는 Supabase Edge Function Secrets에만 보관한다. 채팅, VITE_ 환경변수, 저장소, APK에 기록하지 않는다.

2026-10-16 공급자 확인 결과
- 공개 모델 endpoint 메타데이터에서 vertex 경로는 has_zdr=true, has_no_training=true이며 미국 us-east5 및 EU europe-central2가 안내되어 있다.
- 서버는 only:["vertex"]와 disallowPromptTraining:true를 요청한다. 다른 모델·제공업체로 자동 전환하지 않는다. 모델 비밀 설정도 google/gemini-2.5-flash-lite와 일치해야 한다.
- Vercel 문서상 별도 강제 ZDR 라우팅 옵션은 Pro/Enterprise 대상이다. Hobby에 유료 업그레이드를 수행하지 않았으며 zeroDataRetention:true를 설정하거나 계정 수준 ZDR 강제를 보장하지 않는다.
- Vercel은 Gateway의 프롬프트/출력 본문 미보관 정책을 안내한다. 기술적인 라우팅 상세는 30일 보관, 요청 목록 조회는 최대 36일로 안내되어 있으며 본문과 구분한다. 공급자 보안·과금 기록 전체가 즉시 삭제된다고 약속하지 않는다.
- 앱 및 current/privacy-policy.en.txt의 13항에 공급자, 데이터, 목적, 선택·거절, 국외 처리 가능성, 초안 및 사용량 기록 보관과 보호자 제한을 명시했다.
- 공개 출시 전 실제 계약 법인·DPA/재위탁, 계정별 설정·처리국가·보관 조건과 지출 한도 확인이 남아 있다. 실제 AI 생성도 아직 검증 전이다.
