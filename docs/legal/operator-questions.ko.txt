운영자 확인 질문 — 2026-10-15
답변은 이 목록 번호를 기준으로 채팅에 적어주면 됩니다. 비밀키, 비밀번호, 이용자의 실제 이메일/대화 내용은 필요하지 않습니다.

1. 운영 주체
- 개인 운영 / 개인사업자 / 법인 중 무엇인가요?
- 공개할 운영자 성명 또는 회사/사업자명은 무엇인가요?
- 운영 국가와 공개 가능한 사업 연락처/소재지는 어디인가요? 주소를 이 채팅에 적기 부담스럽다면 '별도 입력 예정'으로 표시할 수 있습니다.
- 개인정보 문의·일반 고객 문의에 admin@getpickleapp.com을 사용할까요? 다른 주소를 사용할 경우 알려주세요. 현재 support@pickle.app은 실제 관리하는 주소인가요?

2. 출시 범위와 연령
- 최초 출시 국가/지역은 어디인가요?
- 최소 가입 연령은 어떻게 할까요? 현재 문구는 만 13세 미만 대상이 아니라고만 되어 있습니다.
- 아동/청소년 대상 서비스인지, 연령 확인·보호자 동의가 필요한 범위를 검토해야 합니다.
- 공식 문서는 영어만 제공할까요, 한국어도 정식 버전으로 제공할까요?

3. 탈퇴 후 게시물
- 계정 삭제 시 게시한 레시피/사진도 함께 삭제할까요?
- 또는 작성자 식별 정보를 제거하고 레시피를 유지할까요? 이 경우 사진·본문에 포함된 개인정보 처리까지 결정해야 합니다.
- 대화 상대의 메시지 사본은 현재 계정 삭제 시 함께 제거되는 구조입니다. 이 방식 유지 여부도 확인이 필요합니다.

4. 항목별 보관 기간/정책
- 신고 원문·증거·관리자 메모·제재·이의신청 기록
- 검색 기록/통계
- 인증·보안·호스팅 로그
- 이메일 발송 기록과 공급자 기록
- 동의 증빙
- DB/파일 백업
- 미정이면 '미정, 권장안 제시'라고 답해주세요. 반복 위반 90일과 추천 검색 30일은 실제 데이터 보관 만료 기간이 아닙니다.
- 법률상 보관해야 하는 항목이나 진행 중 분쟁이 있다면 해당 사유를 알려주세요. 법률상 기간을 모르면 모른다고 답하면 됩니다.

5. 공급자/외부 처리
- 실제 웹 호스팅 업체는 어디인가요?
- 공식 메일함을 수신·관리하는 업체는 어디인가요?
- Google/Apple 로그인 중 실제 활성화한 것은 무엇인가요?
- 광고·마케팅 이메일·외부 분석·오류 수집 서비스가 있거나 출시 때 추가할 계획인가요?
- Supabase/Resend의 보관 설정·계약·처리 국가를 확인할 수 있나요? 확인 불가면 미확인으로 남깁니다.

6. 공개 URL/담당자
- 공개 개인정보처리방침·약관과 앱 밖 탈퇴 요청 페이지에 사용할 공식 도메인/경로가 정해졌나요?
- 개인정보 요청·신고·이의신청 처리 담당자는 누가 맡나요? 최초에는 동일 운영자가 맡을 수 있지만 실제 수행 가능한 절차가 필요합니다.
- 유료 기능/구독/광고 등 수익 모델이 예정돼 있다면 알려주세요. 아직 없으면 현재 없는 기능의 결제·광고 동의 문구를 넣지 않습니다.

답변 확정 후에는 문구뿐 아니라 실제 삭제/보관/동의 기록 기능이 그 문구와 일치하는지도 확인합니다.
